# Рука цела

3D-игра на Three.js: каракурт исследует ночную спальню и прокладывает маршрут через мебель и кровать к кисти спящего человека. Основные объекты загружаются из реальных GLB-моделей; архитектура комнаты, мелочи и звук создаются кодом.

## Запуск

Нужен Node.js 22.14 или новее.

```sh
npm install
npm run dev
```

Откройте в Google Chrome адрес, который напечатает Vite. Сборка: `npm run build`. Содержимое `dist` размещается на HTTP-сервере; `file://` не поддерживается.

## Управление

- WASD — движение по поверхности; направьте камеру на стену и нажмите W для подъёма.
- Мышь — обзор после захвата указателя; без захвата удерживайте ПКМ.
- Пробел — прыжок, Shift — бег, Ctrl — подкрадывание.
- ЛКМ или E — удерживать нить; W на нити — подтягиваться. Отпускание освобождает нить.
- Q или Ctrl у края — спуск на страховочной нити; двигайтесь к краю перед спуском.
- R — аварийное возвращение на последнюю безопасную точку.
- F3 — коллайдеры и диагностические лучи.
- Esc — пауза. В меню доступны продолжение и возврат к чекпоинту.

Останавливайтесь у подсвеченных целей, чтобы закрепить маршрут. Шум зависит от скорости и материала поверхности. Таймер отсчитывает время прохождения, рекорд хранится в localStorage. При недоступности хранилища игра работает без сохранения.

## Модели и авторы

Оригиналы находятся в `source-models`, распакованные копии — в `source-models/extracted`, игровые ресурсы — в `public/models`. Подготовленные девять GLB занимают около 14,95 МБ. Кровать содержит 124 981 треугольник; геометрия сжата Meshopt, текстуры — WebP. Размеры комнатной сцены заданы в метрах, внутренние единицы физики переводятся коэффициентом 0,15. Размер паука задаётся `SPIDER_SCALE` в `src/assets.js`.

- **Black widow spider** — [majidakbarimoganjogi](https://sketchfab.com/majidakbarimoganjogi), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- **bed** — [hectopod](https://sketchfab.com/hectopod), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Диван, стол, стеллаж, лампа, картины и статуэтка — [Poly Haven](https://polyhaven.com/), CC0.
- Человек — пользовательский архив `3dexport_blender_file_1733305010.zip`. Автор и лицензия отсутствуют в архиве: право распространения необходимо подтвердить до публикации.

Изменения моделей и ограничения указаны в [CREDITS.md](CREDITS.md). GLTF кресла отсутствует; запрещённый BLEND-дубликат и запасной паук в игру не включены. У основного паука есть клип `Take 001`; визуальная приёмка походки ещё не завершена.

## Графика и звук

По умолчанию выбрано высокое качество. Автоматическая настройка игнорирует первые 12 секунд и ставит снижение в очередь после четырёх секунд устойчивого FPS ниже 40. Изменение применяется только в безопасном состоянии; ручной выбор имеет приоритет. Bloom, глубина резкости, виньетка и зерно реализованы через EffectComposer. Лучи света — полупрозрачная геометрия, не физический объёмный raymarching. Звук синтезируется WebAudio после пользовательского действия.

## Проверки и текущие ограничения

```sh
npm test
npm run build
npm run format:check
npm run test:chrome -- http://127.0.0.1:PORT
```

В последней команде замените адрес на фактический адрес Vite. Тест использует установленный Google Chrome. `tests/route-pilot.mjs` — отдельный длительный прогон маршрута с трассировкой DevTools; его обходные точки пока требуют адаптации к импортированной мебели. Успех модульных тестов не означает прохождение всей игры.

Исправлено преобразование нормализованных целочисленных атрибутов Meshopt в Float32 перед созданием коллизий. Добавлен регрессионный тест. Полное прохождение всех зон, положение открытой руки на одеяле, анимация человека и стабильные 55+ FPS по всему маршруту пока не приняты. Цель 60 FPS не является подтверждённой гарантией.

## Сцена укуса и отладка

После завершения маршрута запускается девятисекундная сцена без управления. Текст финала задаётся в `src/strings.js`. После первого полного просмотра Esc или пробел пропускает повторный показ, но только через 1,5 секунды. Итоговый экран показывает время, обнаружения, поражения и рекорд.

В dev-режиме `?debug` или F3 открывает выбор страховочной точки, телепорт и запуск сцены укуса. В production-сборке эти инструменты и `window.gameDiagnostics` отключены. Отладочное прохождение не записывает рекорд.

`node tests/ending-chrome.mjs http://127.0.0.1:PORT` проверяет сцену отдельно в установленном Google Chrome. Это проверка через отладочный переход, не доказательство непрерывного прохождения. Снимки: `artifacts/ending-approach.png`, `artifacts/ending-bite.png`, `artifacts/ending-result.png`.

Непрерывный автопилот пока не проходит весь путь: последние попытки остановились в зоне подушки либо завершились поражением от мухобойки. Двух успешных прохождений и гарантии 55+ FPS на всём пути нет.

## Структура

- `assets`, `model-world`, `model-human`, `model-spider` — загрузка и размещение моделей.
- `collision-geometry`, `physics`, `player`, `camera`, `input` — коллизии и управление.
- `rope`, `route`, `model-route`, `game` — нить, маршрут, состояния игры.
- `threat`, `enemies`, `audio` — человек, препятствия и звук.
- `effects`, `quality`, `ui`, `main` — изображение, интерфейс и игровой цикл.
- `tools` — подготовка ассетов; `artifacts` — отчёты и снимки проверок.
